2. 선택 기능과 접근 권한

  • 아이폰 캘린더: 이용자가 연동을 켜고 권한을 허용한 경우 선택한 캘린더의 일정을 조회·작성·수정합니다. 일정은 해당 캘린더 계정과 iOS 동기화 설정에 따라 처리됩니다. 연동을 꺼도 기존 캘린더 일정이 삭제되지는 않습니다.
  • 알림: 알림을 선택하고 권한을 허용하면 iOS가 기기 알림을 예약합니다.
  • 날씨: 기본 설정은 꺼짐입니다. 켜고 지역을 직접 선택한 경우에만 기상청에 예보를 요청합니다. 위치 접근 권한을 요청하지 않고, 이 설정을 공유 계정에 연결해 저장하지 않습니다.
  • 파일·백업: 이용자가 내보내기·가져오기를 선택하면 직접 선택한 파일에 접근합니다. 내보낸 파일과 기기·iCloud 백업은 이용자가 선택한 저장 위치와 iOS 설정에 따라 관리됩니다.
  • 위젯: 현재 위젯은 월 달력·오늘·공휴일을 표시하며 개인 일정 내용은 표시하지 않습니다.

선택 권한을 허용하지 않아도 기본 개인 기록 기능을 사용할 수 있습니다. 캘린더·알림 권한은 아이폰 설정에서 변경할 수 있습니다.

공유달력에 직접 등록한 일정과 작성자의 표시 이름은 해당 달력에 접근할 수 있는 참여자에게 표시됩니다. 참여자는 일정을 조회·작성·수정·삭제할 수 있으며, 다른 참여자가 수정해도 최초 작성자는 유지됩니다. 개인 달력의 내용은 로그인만으로 공유되지 않습니다.

운영자는 이용자 정보를 판매하거나 광고에 사용하지 않습니다. 이용자가 선택한 공유·연동, 서비스 운영에 필요한 처리, 법령에 따른 경우를 제외하고 별도 목적으로 공개하지 않습니다.

4. 보관 기간과 삭제

  • 개인 기록: 이용자가 삭제하거나 앱 데이터가 제거될 때까지 기기에 보관합니다. 별도로 내보낸 파일·기기 백업은 자동 삭제되지 않으므로 이용자가 직접 관리합니다.
  • 공유 계정·프로필: 계정을 유지하는 동안 보관하고, 계정 삭제가 완료되면 운영 DB의 계정·프로필·참여 정보를 삭제합니다.
  • 공유 일정: 일정 또는 달력을 삭제할 때까지 보관합니다. 계정 삭제 시 내가 만든 공유달력과 그 일정도 삭제됩니다. 다른 사람이 만든 달력에 작성한 일정은 남지만 작성자 계정·프로필 연결은 제거됩니다. 일정 내용도 지우려면 계정 삭제 전에 해당 일정을 삭제하거나 문의해 주세요.
  • 삭제 표시: 늦게 도착한 저장 요청이 삭제한 일정을 복원하지 못하도록 일정 식별자와 삭제 상태는 달력 삭제 시까지 남을 수 있습니다. 삭제한 일정의 본문·날짜·시간·작성자 정보는 제거합니다.
  • 날씨: 지역 설정은 기기에 보관하고 변경·앱 데이터 제거 시 갱신·제거됩니다. 받은 예보는 메모리 캐시이며 앱을 종료하면 사라집니다. 날씨 표시를 끄면 추가 예보 요청과 표시를 중단합니다.
  • 문의: 답변·권리 요청 처리가 끝난 뒤 1년 이내 삭제합니다. 분쟁이나 법령상 보관 의무가 있으면 그 사유가 끝날 때까지 필요한 정보만 별도 보관합니다.

외부 서비스의 보안 로그와 복구용 사본은 운영 DB의 즉시 삭제와 다른 주기를 가질 수 있습니다. Supabase 로그·백업의 보관은 이용 요금제 및 해당 서비스 정책에 따르며, 정확한 처리 범위나 삭제 요청은 아래 연락처로 문의할 수 있습니다. 운영자는 불필요한 별도 일정 백업이나 사용자 행동 분석 로그를 만들지 않습니다.

전자 정보는 복구가 어렵도록 삭제하고, 법령에 따라 보관해야 하는 경우에는 해당 목적에 한해 분리하여 관리합니다.

5. 이용자의 권리와 선택

이용자는 개인정보의 열람·정정·삭제·처리 정지 및 동의 철회를 요청할 수 있습니다. 앱에서 일정을 직접 수정·삭제하거나 공유달력의 내 계정에서 공유 계정 삭제를 선택할 수 있습니다. 권리 요청은 이메일로도 접수하며, 계정 소유 확인에 필요한 최소 정보만 요청합니다.

공유 계정을 삭제해도 기기의 개인 기록은 유지됩니다. 로그아웃하면 앱은 기기에 보관된 로그인 세션을 삭제하며, 운영체제의 Keychain 정책에 따라 앱 삭제만으로 세션이 모두 제거된다고 보장되지는 않으므로 공용 기기에서는 먼저 로그아웃해 주세요.

권한을 철회하거나 공유 기능을 사용하지 않아도 개인 달력은 사용할 수 있습니다. 공유 데이터 처리를 거부하면 공동 편집·공유 로그인 등 관련 기능의 이용은 제한됩니다.

6. 보호 조치와 웹사이트

서버 통신에는 HTTPS를 사용하고, 공유 일정은 인증과 달력 참여 권한 검사로 접근을 제한합니다. 로그인 세션은 Keychain에 보관하며 서버 관리자 비밀키를 앱에 포함하지 않습니다.

이 웹사이트는 정적 안내 페이지로, 별도의 회원가입 양식·광고·분석 스크립트·추적 쿠키를 사용하지 않습니다. 다만 호스팅 제공자인 GitHub는 보안을 위해 방문자의 IP를 기록합니다. 문의 메일에는 비밀번호·인증 코드·초대 코드·개인 일정 원문을 보내지 마세요.
